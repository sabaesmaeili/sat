# SAT prep: rules for AI sessions

Read `README.md` (layout, commands, design, palette, publishing) and `bank/README.md` (the bank format) first.

## The bank

- `bank/original/` holds only the College Board's text, verbatim, with `"origin": "original"`: nothing reworded, corrected, completed or smart-quoted. A doubt goes in the item's `notes`, never into a silent fix. Typed from `img/<section>/` screenshots.
- `bank/annotations/` holds only our words (card, card link, hint), keyed by item id. Never put ours in `original/` or the College Board's in `annotations/`.
- The existing sections of `bank/README.md` are the format; change them only with the owner. New items arrive through `tools/import_staging.py` (README, "Add a question").
- Item ids are the drills' progress keys (localStorage `sat-drill80-writing`, `sat-drill80-math`): never rename an id or change those keys.

## Before committing

- Run `python3 tools/check.py`; it must pass. It validates the bank (including the HTML and math rules in README, "What reaches a page"), the annotations (every item has a card; every anchor exists on its cheat sheet), the token copies, the palette, the grading of typed answers (`tools/test_grading.js`, with node), and every link and anchor in a fresh build.
- `_site/` is generated; never commit it. Stage only the paths you changed (no `git add -A`).

## Design sources

- Website design system: `~/Documents/GitHub/Website/docs/design-system.xml` and `src/styles/global.css`. `site/css/tokens.css` is generated from it by `tools/sync_tokens.py`; never edit it by hand.
- French tool: `~/Documents/GitHub/Projects/French/_Workspace/tool/DESIGN.md` (type rule §1–2, header and address §4, prompts and tree rows §5) and `tool-tokens.css`, copied to `site/css/tool-tokens.css` by `tools/sync_tokens.py`; never edit the copy.
- `site/css/palette.css` is generated by `tools/palette.py`; change hues there, never in the CSS. One value per hue per mode, named `--color-<hue>`; greys only from the tokens.
- Keep the cheat-sheet cards' layout, navigation (picker, anchors) and math format; the drills' behaviour is the original pages'.
- Drill pages carry `<meta name="robots" content="noindex">`; nothing else does. All links stay relative.

## Safety

- Never rewrite history: no force-push, amend, rebase or filter of pushed commits; merge with merge commits.
- Never discard uncommitted work (`git reset --hard`, `git clean`, `git checkout -- .`). Deleting a tracked file is an ordinary commit, after the owner confirms.
